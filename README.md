# Локальный AI-агент с RAG для работы в изолированном контуре (Air-Gapped)

Автономная программная система для автоматизированного прохождения онлайн-тестов и экзаменов на ПК без доступа к сети Интернет. Агент считывает вопросы и варианты ответов со страницы браузера, находит релевантные фрагменты в локальной векторной базе нормативных документов (`.pdf`, `.docx`, `.txt`) и выбирает правильные варианты с помощью локально запущенной языковой модели.

## Архитектура и технологический стек

Система полностью независима от внешних облачных API и работает в замкнутом контуре:

| Компонент | Технология / Модель | Назначение |
| :--- | :--- | :--- |
| **Инференс-движок** | Ollama (Linux `x86_64`) | Локальный запуск LLM и моделей эмбеддингов по REST API (`127.0.0.1:11434`) |
| **Языковая модель (LLM)** | `Qwen2.5-7B-Instruct-GGUF` (`Q4_K_M`) / `qwen3:1.7b` | Анализ вопроса, сопоставление с нормативным текстом и генерация ответа в формате JSON |
| **Модель эмбеддингов** | `bge-m3-GGUF` (`Q8_0`) | Векторизация нормативных документов и поисковых запросов на русском языке |
| **Векторная БД (RAG)** | ChromaDB (`PersistentClient`) | Локальное хранение индексов нормативных актов и методических материалов (`./exam_db`) |
| **Автоматизация браузера** | Python + Playwright (Chromium / Яндекс Браузер) | Управление браузером, парсинг DOM-структуры модального окна теста и клики по вариантам |

## Структура оффлайн-бандла

Для переноса на изолированный ПК формируется единый архив `offline_ai_agent_bundle.tar` со следующей структурой:

```text
offline_ai_agent_bundle/
├── app/
│   ├── agent.py                    # Основной скрипт AI-агента
│   ├── exam_db/                    # Предварительно проиндексированная база ChromaDB (коллекция exam_materials)
│   └── docs/                       # Исходные нормативные документы (.pdf, .docx, .txt)
├── models/
│   ├── blobs/                      # Бинарные веса моделей (sha256-...)
│   └── manifests/                  # Манифесты и теги моделей Ollama
├── ollama/
│   └── ollama-linux-amd64.tar.zst  # Дистрибутив Ollama
├── playwright_browsers/
│   └── chromium-1254/              # Портативный браузер Chromium
├── wheels/                         # Оффлайн-пакеты Python (.whl)
├── install_offline.sh              # Скрипт развертывания на изолированном ПК
├── run_env.sh                      # Генерируемый файл переменных окружения
├── start_agent.sh                  # Единый скрипт запуска сервера и агента
└── README.md                       # Документация проекта
```


## Подготовка бандла (на ПК с доступом в Интернет)

Предварительные требования

- ОС Linux (x86_64), версия Python, совпадающая с целевым ПК (например, 3.11).

- Установленный архиватор zstd (sudo apt-get install -y zstd).

- Минимум 15 ГБ свободного места на диске.

## Сборка оффлайн-архива

Запустите идемпотентный скрипт сборки prepare_bundle.sh (при обрыве сети скрипт пропускает уже скачанные компоненты и докачивает только недостающие):

```Bash
chmod +x prepare_bundle.sh
./prepare_bundle.sh
```

Убедитесь, что в папке models/ присутствуют обе директории (blobs/ и manifests/), а общий размер моделей составляет ~5.3–6 ГБ.

Поместите скрипт agent.py и готовую векторную базу exam_db/ в директорию offline_ai_agent_bundle/app/.

Пересоберите итоговый архив для переноса:

```Bash
tar -cf offline_ai_agent_bundle.tar offline_ai_agent_bundle
```

## Развертывание на изолированном ПК (без Интернета)

Перенесите offline_ai_agent_bundle.tar на целевой компьютер и распакуйте:

```Bash
tar -xf offline_ai_agent_bundle.tar
cd offline_ai_agent_bundle
```

Выполните оффлайн-установку (скрипт распакует Ollama в /usr/local или локально в ./ollama_bin, создаст виртуальное окружение venv и установит зависимости из wheels/):

```Bash
chmod +x install_offline.sh
./install_offline.sh
```


Проверьте корректность установки и наличие весов моделей:

```Bash
source run_env.sh
ollama list
```

В выводе должны отображаться Qwen2.5-7B-Instruct-GGUF и bge-m3-GGUF.

### Конфигурация и эксплуатация агента

Настройка параметров (app/agent.py)

Перед запуском проверьте блок настроек в верхней части файла agent.py:

TEST_URL — адрес учебного портала (например, http://<адрес-портала>/student/programs).

EMBED_MODEL и LLM_MODEL — точные имена моделей из вывода ollama list.

AUTO_CLICK:

True — полностью автоматический режим (выбор варианта и переход к следующему вопросу без пауз, для укладывания в таймер).

False — полуавтоматический режим с подтверждением или ручной корректировкой номера ответа в консоли перед кликом.

Использование Яндекс Браузера (опционально): если на целевом ПК требуется работа через предустановленный Яндекс Браузер, в вызове p.chromium.launch(...) укажите executable_path="/usr/bin/yandex-browser".

Сценарий работы во время тестирования
Запустите систему одной командой из корня распакованной папки:

```Bash
./start_agent.sh
```

Скрипт автоматически запустит фоновый сервер ollama serve, прогреет модели в оперативной памяти (5–15 сек.) и откроет окно браузера.

Действия оператора в браузере (таймаут ожидания — до 5 минут):

Выполните вход под учетной записью обучающегося.

В левом дереве навигации (.tree) выберите программу обучения и раздел/нормативный акт.

Нажмите кнопку «Режим обучения» или «Начать Экзамен».

## Автоматическое прохождение:

Как только модальное окно #react_exam станет видимым, агент перехватит управление.

Для каждого вопроса скрипт очищает текст из #react_exam .plain (исключая таблицу вариантов), запрашивает 3 релевантных фрагмента из ChromaDB, определяет одиночный (radio) или множественный (checkbox) выбор и кликает по соответствующим элементам <label>.

На последнем вопросе агент автоматически подтверждает завершение в окне #react_confirm и выводит итоговый результат из #alert_confirm.

## Диагностика и решение типовых проблем

| Симптом / Ошибка | Причина | Решение |
| :--- | :--- | :--- |
| `Looks like Playwright was just installed...` | Не задана переменная `PLAYWRIGHT_BROWSERS_PATH` или в папке отсутствует полный `chromium-1254` | Запускайте скрипт строго через `./start_agent.sh` (или предварительно выполните `source run_env.sh`), либо укажите `executable_path` на системный браузер |
| `redirect target not allowed: ... resolves to non-public 198.18.x.x` (при сборке) | Включен TUN/Fake-IP прокси на машине сборки; SSRF-защита Ollama блокирует редирект | Скачивайте веса напрямую с Hugging Face (`hf.co/...`) или передайте `HTTPS_PROXY` серверу `ollama serve` |
| `listen tcp 127.0.0.1:11434: bind: address already in use` | В фоне остался висеть предыдущий экземпляр `ollama serve` | Выполните `pkill -f ollama` перед повторным запуском |
| Низкая скорость генерации ответа | Недостаточно ОЗУ или модели выгружаются из памяти | Убедитесь, что функция `warmup_models()` отработала до начала таймера, либо переключитесь на более легкую модель (`qwen3:1.7b` или `qwen2.5:3b`) |
